Machine Learning
Machine learning (ML) is a field of inquiry devoted to understanding and building methods that 'learn', that is, methods that leverage data to improve performance on some set of tasks.


AI wo Khawab hai (Machine ko smart banana), ML wo Tareeqa hai (Data se seekhna), aur DL wo Advanced Tool hai (Neural Networks ke zariye insani dimaagh ki tarah gehraai mein seekhna).
